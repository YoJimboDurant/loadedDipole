# Plot inductance vs turns for a given PVC coil form

Plot inductance vs turns for a given PVC coil form

## Usage

``` r
plot_coil_turns(
  pvc_size = "1-1/2",
  wire_diameter = 0.064,
  turn_spacing = NULL,
  N_range = 5:150
)
```

## Arguments

- pvc_size:

  PVC nominal size.

- wire_diameter:

  Wire diameter in inches.

- turn_spacing:

  Turn spacing in inches.

- N_range:

  Range of turns to evaluate.
