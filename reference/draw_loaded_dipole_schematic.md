# Draw a dipole schematic to PNG for a loaded dipole design

Draw a dipole schematic to PNG for a loaded dipole design

## Usage

``` r
draw_loaded_dipole_schematic(design, file, width = 9, height = 3)
```

## Arguments

- design:

  The output list from
  [`design_loaded_dipole_full()`](https://yojimbodurant.github.io/loadedDipole/reference/design_loaded_dipole_full.md).

- file:

  Output PNG file path.

- width:

  Width in inches.

- height:

  Height in inches.

## Value

Invisibly, the file path.
