# Draw a dipole schematic and return a Base64 string

Draw a dipole schematic and return a Base64 string

## Usage

``` r
draw_loaded_dipole_schematic_base64(design, width = 9, height = 3)
```

## Arguments

- design:

  Design object from
  [`design_loaded_dipole_full()`](https://yojimbodurant.github.io/loadedDipole/reference/design_loaded_dipole_full.md).

- width:

  Width in inches.

- height:

  Height in inches.

## Value

Base64-encoded PNG suitable for HTML embedding.
